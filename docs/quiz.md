# ゲームルール

## 概要

このアプリケーションは「早押しクイズ」の補助ツールです。  
早押しボタン機能を提供し、ボイスチャットや文字チャットでの解答をサポートします。

---

## 早押しクイズ（メイン機能）

### 基本の流れ

1. **問題文の読み上げ** - 司会者が問題を出題
2. **ボタン押下（早押し）** - 解答者がボタンを押して解答権を獲得
3. **解答** - ボイスチャットまたは文字チャットで解答
4. **正誤判定** - 司会者が正誤を判定し、ポイントを加減算

### 解答方法

| 方法 | 説明 |
|------|------|
| **ボイスチャット** | 音声で直接解答を伝える |
| **文字チャット** | チャット機能を使って解答を送信 |

---

## 対応ルール

### 実装優先度

| 優先度 | ルール | 状態 |
|--------|--------|------|
| 🥇 高 | m○n× | **最優先** |
| 🥈 中 | m○n休 | 今後実装 |
| 🥈 中 | NbyN | 今後実装 |
| 🥈 中 | プラス1マイナス1 | 今後実装 |

---

### m○n×（エムマルエンバツ）🥇

**最優先で実装するルール**

- **m回正解**で勝ち抜け、**n回誤答**で失格

| 項目 | 説明 |
|------|------|
| 正解時 | ○（正解数）が1増加 |
| 誤答時 | ×（誤答数）が1増加 |
| 勝ち抜け条件 | ○がm個に到達 |
| 失格条件 | ×がn個に到達 |

#### 設定例

| 設定 | 特徴 |
|------|------|
| **7○3×** | 定番ルール。バランスが良い |
| **5○2×** | スピーディー。誤答に厳しい |
| **10○4×** | 長丁場。実力が反映されやすい |

---

### m○n休（エムマルエンキュウ）

- 誤答すると**n問の間、解答権を失う**（失格にはならない）

| 項目 | 説明 |
|------|------|
| 正解時 | ○が1増加 |
| 誤答時 | n問の間、ボタンが押せなくなる |
| 勝ち抜け条件 | ○がm個に到達 |
| 失格条件 | なし |

#### 設定例

| 設定 | 特徴 |
|------|------|
| **7○3休** | 定番。誤答のペナルティが軽め |
| **5○5休** | 誤答のペナルティが重い |

---

### NbyN（エヌバイエヌ）

- 縦軸（正解数）と横軸（誤答数）のマトリクスで管理
- 「N正解かつN誤答未満」で勝ち抜け

| 項目 | 説明 |
|------|------|
| 正解時 | 正解数が1増加 |
| 誤答時 | 誤答数が1増加 |
| 勝ち抜け条件 | N正解に到達（誤答数がN未満の状態で） |
| 失格条件 | 誤答数がNに到達 |

- 誤答を恐れず積極的に押す戦略が有効

---

### +N/-M形式（ポイント加減算）

- 正解で**+Nポイント**、誤答で**-Mポイント**
- ポイントは0未満になる可能性あり

| 項目 | 説明 |
|------|------|
| 正解時 | +Nポイント |
| 誤答時 | -Mポイント |
| 勝ち抜け条件 | 設定したポイントに到達 |
| 失格条件 | なし（または設定したマイナスポイントに到達） |

#### 設定例

| 設定 | 特徴 |
|------|------|
| **+1/-1 で 7pt勝抜** | 定番。シンプルで分かりやすい |
| **+2/-1 で 10pt勝抜** | 正解優遇。積極的に押しやすい |
| **+3/-3 で 10pt勝抜** | 早押しボード向け。ハイリスク・ハイリターン |
| **+1/-1 で 7pt勝抜 / -3pt失格** | 誤答に制限あり |

#### ボタン未押下者へのポイント（オプション）

早押しボードクイズなど、ボタンを押していない解答者にもポイントが入る形式：

| 対象 | 正解時 | 誤答時 |
|------|--------|--------|
| **ボタン押下者** | +Nポイント | -Mポイント |
| **ボタン未押下者** | +Aポイント（任意） | 0ポイント |

例: ボタン押下者 +3/-3、未押下者 +1/0

## 早押しボードクイズ（おまけ機能）

1. 問題文の読み上げ開始
2. **誰かがボタンを押すと問題文が停止**
3. **全員がボードに解答**（ボタン押下者以外も解答可能）
4. 正解発表・ポイント計算

### ポイントシステム(例)

| 条件 | 正解 | 不正解 |
|------|------|--------|
| **ボタンを押した人** | +3ポイント | -3ポイント |
| **ボタンを押していない人** | +1ポイント | 0ポイント |

---

## 参加者の役割

| 役割 | 説明 |
|------|------|
| **司会者（ホスト）** | ルーム作成、問題の出題、正誤判定、ポイント管理 |
| **解答者（プレイヤー）** | 早押しボタンを押し、解答を行う |
| **観戦者** | 解答には参加せず、ゲームを観戦する |

---

## 誤答時の追加ルール

### 回答制限（休みルール）

| ルール名 | 説明 |
|----------|------|
| **一問休み** | 誤答したその問題の再回答ができない |
| **一答休み** | 連続しては回答できないが、他の誰かが誤答すれば再度回答できる |
| **一回休み** | 誤答のペナルティとして「次の問題」も回答できない |

### 回答権の遷移（誤答後の処理）

| ルール名 | 説明 |
|----------|------|
| **シングルチャンス** | 誰かが誤答した時点でその問題は終了 |
| **エンドレスチャンス** | 誤答しても問題文が続きから読まれ、他の人が回答可能 |
| **2着切り** | 1人目が誤答した際、既にボタンを押していた2人目が回答できる |
| **全順回答** | ボタンを押した順に、全員に回答機会がある |
